# Part 0: Your Workshop

*Before we write any Rust, we set up the bench we'll work at: Nix for a toolchain that's identical on every machine, zsh for a shell that helps, tmux for a workspace that survives, and Neovim for an editor that understands Rust's types. Everything is declared in one typed, version-controlled flake, so the workshop is itself a small exercise in the book's central idea: say precisely what you want, and let a checker refuse anything else.*
