# Part III: tdo, a Command-Line To-Do List

*We build `tdo`, a small to-do list for the terminal that remembers every change you have ever made to it. Along the way we parse the command line into domain commands, try typestate on for size and see where it fits, and store facts rather than state, using event sourcing: a pure `decide` and a pure `evolve`, with undo and history falling out of the design.*
